# Changelog

## 1.0.2 — 2026-10-22

- Новая adaptive-иконка с голубой ЭЭГ-волной.
- Отдельный monochrome-слой для тематических иконок Android.

### Changed

- Подписанный release APK для версии 1.0.2.

### Added

- Повышена версия приложения до 1.0.1.

### Added

- Управление списком станций.
