# Contributing

Спасибо за интерес к проекту.

## Сообщения об ошибках

Создайте issue и укажите:

- версию приложения и версию Android;
- модель устройства;
- шаги для воспроизведения проблемы;
- ожидаемое и фактическое поведение;
- логи или скриншоты, если они есть.

## Pull requests

1. Сделайте fork репозитория и создайте ветку от `main`.
2. Внесите изменения и добавьте тесты, если это применимо.
3. Перед отправкой выполните:

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:lintDebug
```

4. Опишите в pull request, что изменилось и зачем.

Для крупных изменений сначала создайте issue, чтобы обсудить подход.
